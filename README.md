# Pandora

Pandora is a frontend application for cleaning, transforming, validating, and previewing Excel and CSV data.

## Live Demo

https://pandora-glm.netlify.app/

## Features

- Excel and CSV file processing
- Column selection and transformation
- Configurable ranges
- Data validation
- Result preview
- Multi-sheet workflows
- End-to-end test coverage

## Tech Stack

- React
- TypeScript
- Vite
- SheetJS
- Playwright

## Development Approach

The product requirements, UX flows, validation rules, and testing scenarios were defined and iteratively refined by me. The implementation was primarily developed using AI-assisted coding, with ongoing review, testing, and refinement.
